# Surowe wyniki pomiarów

Każdy plik to niezmieniony wynik przebiegu narzędzia z repozytorium, z datą, commitem, wersją Go, systemem
i maszyną w nagłówku albo w pliku `environment-*.json` obok. Liczby w README, w `../comparison.md`
i w `../testing.md` dają się z tych plików wyprowadzić; sposób jest w `../methodology.md`. Pliki zastępuje nowy
przebieg tym samym narzędziem, nigdy ręczna poprawka.

Jeszcze pusto: pierwsze pliki powstają w etapie 3.
